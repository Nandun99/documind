# DocuMind

DocuMind is a RAG (Retrieval-Augmented Generation) assistant that answers questions about your own documents. Upload PDFs, Word files or text files and ask questions in plain English. Every answer is based only on your documents and cites the exact sources it used.

> Status: in progress

## Features

- Upload **PDF, DOCX, TXT and Markdown** files (drag and drop)
- Documents are split into overlapping chunks, embedded with **OpenAI embeddings** and stored in **ChromaDB**
- Answers generated by a **GPT model** using only the retrieved chunks, with inline citations like `[1]`
- Click a citation to see the source chunk, file name, page number and match score
- **Streaming answers** over Server-Sent Events
- Ask across all documents or only the ones you select
- Conversation history with follow-up questions
- **Token usage, estimated cost and latency** shown for every answer
- Skips the model call when nothing relevant is found, which saves tokens
- Duplicate upload detection (SHA-256)
- **Offline mode** with no API key, for tests and demos

## How It Works

```
Upload ─► Parse (pypdf / python-docx) ─► Split into chunks ─► Embed ─► ChromaDB
                                                                         │
Question ─► Embed ─► Similarity search (top k, relevance cutoff) ◄───────┘
                │
                ▼
     Prompt = system rules + numbered context + chat history + question
                │
                ▼
          GPT model ─► streamed answer with [n] citations + sources + usage
```

## Tech Stack

| Layer | Tools |
|-------|-------|
| Backend | Python 3.12, FastAPI, LangChain, OpenAI API, ChromaDB, SQLModel (SQLite) |
| Frontend | React 19, TypeScript, Vite, Tailwind CSS |
| Testing | pytest (runs fully offline) |
| Deployment | Docker, Docker Compose, Nginx |

## Project Structure

```
backend/
  app/
    main.py              FastAPI app factory
    config.py            settings from environment / .env
    models.py            SQLModel tables (documents, conversations, messages)
    routers/             documents, chat and health endpoints
    services/
      loaders.py         PDF, DOCX and text parsing
      chunking.py        recursive text splitting
      embeddings.py      OpenAI or offline hashing embeddings
      vectorstore.py     ChromaDB wrapper
      llm.py             OpenAI chat model or offline extractive model
      rag.py             retrieval, prompt building, citations, usage and cost
      ingest.py          background ingestion pipeline
  tests/
frontend/
  src/
    api/                 REST and streaming client
    hooks/               documents, conversations and chat state
    components/          upload, document list, chat, sources, usage
```

## Getting Started

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env             # add your OPENAI_API_KEY
uvicorn app.main:app --reload
```

API docs: http://localhost:8000/docs

No API key? Run fully offline:

```bash
LLM_PROVIDER=local EMBEDDING_PROVIDER=local uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. The dev server proxies `/api` to the backend.

### Docker

```bash
cp backend/.env.example backend/.env   # add your key
docker compose up --build
```

Open http://localhost:8080.

## API

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/documents` | Upload a file (processed in the background) |
| GET | `/api/documents` | List documents and their status |
| GET | `/api/documents/{id}` | Get one document |
| DELETE | `/api/documents/{id}` | Delete a document and its vectors |
| POST | `/api/chat` | Ask a question, returns answer, sources, usage and timings |
| POST | `/api/chat/stream` | Same as above, streamed as Server-Sent Events |
| GET | `/api/conversations` | List conversations |
| GET | `/api/conversations/{id}/messages` | Messages of a conversation |
| DELETE | `/api/conversations/{id}` | Delete a conversation |
| GET | `/api/health` | Health check |

## Configuration

All settings can be set as environment variables or in `backend/.env`.

| Variable | Default | Description |
|----------|---------|-------------|
| `OPENAI_API_KEY` | | OpenAI API key |
| `LLM_PROVIDER` | `openai` | `openai` or `local` |
| `EMBEDDING_PROVIDER` | `openai` | `openai` or `local` |
| `CHAT_MODEL` | `gpt-4o-mini` | Chat model |
| `EMBEDDING_MODEL` | `text-embedding-3-small` | Embedding model |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | `1000` / `150` | Chunking (characters) |
| `TOP_K` | `4` | Chunks retrieved per question |
| `MIN_RELEVANCE` | `0.2` (OpenAI) | Chunks below this score are ignored |
| `MAX_HISTORY_MESSAGES` | `6` | Previous messages sent with each question |
| `MAX_UPLOAD_MB` | `20` | Upload size limit |
| `INPUT_COST_PER_1M` / `OUTPUT_COST_PER_1M` | `0.15` / `0.60` | Prices used for the cost estimate |
